# landingsite.ai
AI landing site and brand experience for Serene Creations

## Login page (Supabase Auth)

`login/index.html` is a static email/password sign-in and sign-up page. Project URL and publishable key are in `login/config.js`.
In Supabase: Authentication > URL Configuration, add the page's final URL to Site URL / Redirect URLs.
To use on landingsite.ai, host these files (or paste the page into a custom-code/embed block) and link to it.
